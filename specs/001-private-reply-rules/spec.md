# Feature Specification: 私聊回应、主动联系额度与当前引用目标

**Feature Branch**: main
**Created**: 2026-09-10
**Status**: 本地受控验收通过；2026-09-11 发布证据见 [validation.md](validation.md)。

## User Scenarios & Testing

### User Story 1 - 每条有效私信都有回应 (Priority: P1)

平台可接收、可路由的用户私信全天具有回应资格。每条独立私信得到可感知的文字或其他合法内容；说明、澄清和请求判断属于有效回应。

| 适用条件 | 验收结果 |
| --- | --- |
| 工作时段内外、各关系等级或主动额度状态 | 有效私信具有独立回应归属 |
| 图片、语音、文件、引用、转发或模型状态变化 | 已支持内容具有相应回应，理解依据明确，必要时返回简短澄清 |
| 同会话连续输入 | 各独立输入按接收顺序具有回应 |
| 同一事件重投 | 原任务、原 run_id 和唯一正常回应保留 |

### User Story 2 - 一轮主动联系最多 3 次 (Priority: P2)

AI 在合适工作时段、关系条件和自然话题下，可于同日多次联系同一用户。每轮额度最多 3 次成功主动联系，该用户的新有效私信建立新一轮额度。

| 适用条件 | 验收结果 |
| --- | --- |
| 计数 0、1、2，作息与间隔满足 | 成功联系后计数为 1、2、3 |
| 计数达到 3 | 状态保留，主动联系资格以新有效私信为条件 |
| 新有效私信 | 对应 AI 与联系人的计数为 0 |
| 跨日、重启、其他人物、群消息或重复输入 | 原联系轮次及额度保留 |
| 生成结果、发送结果及并发预占 | 成功计数以平台确认与唯一预占为依据 |

### User Story 3 - 回复引用当前消息 (Priority: P2)

A 引用 B 时，回复目标为 A，B 的内容与发送者归属保留为历史上下文。

| 适用条件 | 验收结果 |
| --- | --- |
| 私聊、群聊及多层引用 | 当前消息 A 是出站引用目标 |
| 历史引用补全状态变化 | 当前 A 的回应资格和目标保留 |
| 多会话并发 | 每个目标属于对应会话 |
| 当前平台引用资格 | 可引用时指向 A，普通回应适用于相应平台结果 |

## Requirements

### Functional Requirements

- **FR-001**: 平台接收且可路由的独立用户私信全天获得回应处理；有效输入具有可信用户身份及平台消息编号。
- **FR-002**: 回应具有用户可感知内容，简短说明和澄清提供模型或理解状态对应结果。
- **FR-003**: 同会话按接收顺序处理，同一事件具有一个任务和稳定回应归属。
- **FR-004**: 同一 AI 与联系人每轮最多成功主动联系 3 次，轮次保存在持久状态中。
- **FR-005**: 对应用户的新有效私信建立计数为 0 的新轮次，其他事件保持原轮次。
- **FR-006**: 状态采用 ai_id + person_id，平台路由使用完整可信身份记录。
- **FR-007**: 成功联系计数以确认结果为依据，unknown 具有核实状态及当前发送资格边界。
- **FR-008**: 主动联系满足白名单优先级、作息、开关、关系、自然话题及默认 30 分钟间隔。
- **FR-009**: 并发及重启保持固定额度，主动状态恢复具有可信依据，被动回应具有独立资格。
- **FR-010**: A 带引用时，正常回复的引用对象为当前 A。
- **FR-011**: 历史引用内容与发送者保留真实归属，普通回应适用于当前引用资格。
- **FR-012**: 接收、生成、发送与恢复结果可由稳定标识关联，外部恢复采用有限预算。
- **FR-013**: 群聊参与、复读、人物身份、长期记忆、关系评分及受众范围保持各自既有语义。

### Key Entities

有效私信包含输入身份、发送者、会话、时间和内容。主动联系状态包含轮次计数、最近成功时间、新入站依据及发送预占。回应记录关联输入、内容、目标和送达状态。当前 A 与历史 B 具有各自身份。

## Success Criteria

- **SC-001**: 渠道正常的受控场景中有效私信回应覆盖率为 100%，各回应具有可感知内容。
- **SC-002**: 同日第 2、3 次主动联系符合资格；每轮成功联系数至多 3，新有效私信的计数为 0。
- **SC-003**: 各引用边界及并发场景的当前消息目标正确率为 100%。
- **SC-004**: 本地 10 会话、每秒 1 条、持续 10 分钟，模型至多 2 秒、平台确认至多 1 秒时，归属覆盖率 100%，P95 至多 10 秒，error=0。
- **SC-005**: 重启、跨日、重投及竞争场景保持已确认状态；每个输入与动作具有唯一结果，外部状态在 60 秒内可定位。
- **SC-006**: 同样普通文本样本的每条平均模型调用量至多为基线，澄清兜底的额外模型调用数为 0，货币成本依据实际单价和 token。

## Assumptions

一次组合输出计一次主动联系。默认主动间隔为 30 分钟，联系人静默期为 6 小时。渠道送达以平台确认为依据，业务回应义务以有效私信为范围。群聊与主动场景具有各自沉默规则。
