# 独立插件验收目标清单

**Created**: 2026-09-15
**Feature**: [spec.md](spec.md)
**Design**: [architecture.md](architecture.md)
**标记语义**：`[ ]` 表示目标验收项，`[x]` 表示具有完整执行证据的结果。当前交付边界见运行时文档。

每个实际插件的证据包含产物摘要、核心/SDK 摘要、实例 scope、配置/授权修订、环境、入口、operation ID、预期与实际结果。平台模拟及生产实测各有明确范围。
